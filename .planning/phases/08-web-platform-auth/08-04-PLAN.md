# Phase 8 Plan 8-04: React Frontend Website

> Phase: 8 — Web Platform + Authentication
> Plan: 8-04 — React Frontend Website
> Status: Planned
> Depends on: Phase 8-02 (profile + mapping endpoints), existing `website/` React app
> Delivers: Frontend wired to auth/profile endpoints, profile pages, doctor assigns patients UI, protected route coverage

## Objective

Connect the existing React + Vite frontend (already built, lint+build pass) to the auth backend: fetch profiles, expose profile pages, let doctors assign patients, and verify protected route coverage. Backend-connected prediction history is deferred to 8-03.

## Must-Haves

| # | Requirement | Evidence |
|---|---|---|
| 1 | `authAPI` extended: `getProfile()`, `updateProfile()`, `getDoctorPatients()`, `assignPatient(patientEmail)` | `website/src/api.js` |
| 2 | `AuthContext` fetches profile on login and on `/auth/me`, stores it in context | `website/src/contexts/AuthContext.jsx` |
| 3 | Patient profile page (`/profile`): view + edit patient profile fields | `website/src/pages/PatientProfile.jsx` |
| 4 | Doctor profile page (`/doctor-profile`): view + edit doctor profile fields | `website/src/pages/DoctorProfile.jsx` |

| 6 | Protected routes cover all patient-only and doctor-only routes (RoleGate already in App.jsx — verify no gaps) | `website/src/App.jsx` |
| 7 | Register/login flow end-to-end: register → profile create prompt → redirect by role | Existing pages + new wiring |
| 8 | Frontend lint + build pass | `npm --prefix website run lint && npm --prefix website run build` |

## Acceptance Criteria

- [ ] Register a patient → redirected to `/dashboard`; can open `/profile` and see/edit profile
- [ ] Register a doctor → redirected to `/doctor-dashboard`; can open `/doctor-profile` and see/edit profile
- [ ] Doctor can assign a patient via the assigns UI; patient appears in doctor's patient list
- [ ] Patient accessing `/doctor-dashboard` → redirected to `/dashboard` (RoleGate)
- [ ] Doctor accessing `/dashboard` → redirected to `/doctor-dashboard` (RoleGate)
- [ ] `npm --prefix website run lint` + `npm --prefix website run build` both pass

- `ProtectedRoute.jsx` + `RoleGate` in App.jsx already exist — 8-04 verifies coverage and adds profile routes.
- DoctorDashboard/PatientDetail still use static `sample.js` roster — connecting them to backend API is 8-03 (patient-doctor assignment + authenticated predictions).
